# «У Лауры»

Сайт гостевого дома в Лазаревском. Страницы собираются Next.js в каталог `out/`. План реализации и условия запуска описаны в [PLAN.md](PLAN.md).

## Локальный просмотр

Для разработки, сборки и обработчика нужен Node.js 24.

```sh
npm ci
npm run dev
```

Проверки проекта.

```sh
npm run lint
npm test
npm run build
```

## GitHub Pages

Workflow `.github/workflows/pages.yml` при обновлении `main` собирает и публикует `out/` с путём проекта. Предпросмотр исключён из индексации. Приём заявок предусмотрен на основном сайте с подключённым обработчиком. [Условия использования GitHub Pages](https://docs.github.com/en/site-policy/github-terms/github-terms-for-additional-products-and-features#1-github-pages)

## Каталог и тарифы

- `content/rooms.json` содержит категории, вместимость и фотографии. Каталоги фотографий лежат в `public/images/rooms/<id>/`.
- `content/room-rates.json` хранит периоды по категориям. Для каждого периода задаются даты `from` и `through` включительно и целая неотрицательная сумма `nightlyRub`. Периоды одной категории не пересекаются. Пустой файл означает отсутствие подтверждённых ставок.
- `content/site.json` содержит проверенные публичные сведения об объекте, получателях данных, сроке хранения сообщений и версию согласия.

## Обработчик заявок

Обработчик Node.js запускается командой `npm run start:booking`. Timeweb Cloud App Platform подходит для размещения этого процесса. `GET /healthz` возвращает статус запуска. `POST /api/quote` рассчитывает стоимость. `POST /api/request` подтверждает заявку после успешного ответа Telegram. Единственная постоянная копия анкеты — сообщение в личном чате владельца. [Документация Timeweb Cloud](https://timeweb.cloud/docs/apps/deploying-backend-applications)

| Переменная | Назначение |
| --- | --- |
| `SITE_ORIGIN` | Разрешённый HTTPS-источник сайта, например `https://example.ru` |
| `TELEGRAM_BOT_TOKEN` | Секретный токен бота |
| `TELEGRAM_CHAT_ID` | Идентификатор личного чата владельца |
| `REQUESTS_ENABLED` | Значение `true` открывает приём при полной конфигурации |
| `PORT` | Порт процесса, если задан платформой |

Для отдельного HTTPS-адреса обработчика перед сборкой задайте `NEXT_PUBLIC_BOOKING_API_ORIGIN`. Для общего домена направьте `/api/quote` и `/api/request` на процесс Node.js. Боевой приём включается после выполнения [условий запуска](PLAN.md#подключение-telegram).

Гость остаётся на сайте. Если Telegram подтверждает приём, сайт показывает номер заявки. При неопределённом результате уточните в чате владельца, дошло ли сообщение.
